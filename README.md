# 狀態條產生器（繁體中文版）

把 CCFOLIA 角色的 HP、MP、SAN 等數值，用你喜歡的樣式顯示在 OBS 上的「自訂 CSS」產生工具。

本專案是 shiki365「[ステータスバーメーカー](https://shiki365.github.io/status-bar-maker/)」（MIT License）的繁體中文版，功能與原版完全相同，只翻譯介面文字與輸出的 CSS 註解。

直接用瀏覽器開啟 `index.html` 就能使用（不需要伺服器、不需要安裝）。

## 功能

- **9 種設計範本** — 標準（黑底＋紅藍紫）/ 極簡 / 科幻・HUD / 古書（克蘇魯）/ 和風 / 活潑 / 恐怖 / 復古遊戲 / 卡片（含頭像）
- **版面** — 狀態數量（1～8）、直向／橫向／分欄、狀態條尺寸、文字擺放方式（疊在條上／上方／下方／左右排列／只有標籤在外）、角色頭像與先攻值
- **狀態條** — 形狀（圓角、膠囊、平行四邊形、切角、箭頭、單邊斜切）、外框線（可雙線）、底色、填色（單色、漸層、光澤、斜紋、霓虹）、分段、增減速度、逐條的顏色與顯示名稱與圖示
- **文字・名稱** — 34 種字型（16 種繁體中文 Google Fonts ＋ 14 種英數字型 ＋ 本機字型）＋自行輸入本機字型名稱（Chrome / Edge 可從清單看外觀挑選）、大小、描邊、名稱位置（最上方／狀態條上方／最下方／左側直書／疊在頭像上）與外觀
- **效果** — 剩餘量低於 ○% 時發光、閃爍、震動、變色，歸零時變灰，CCFOLIA 的紅色數字（80% 以下）顏色
- **裝飾** — 背景面板（泛黃紙張、顆粒）、整體外框（單線、雙線、虛線、發光線、四角、細線＋四角）、光澤、外緣光暈、前端亮線、流動光線、掃描線、刻度、顆粒感、邊角括號
- **角色清單** — 由房間網址與角色 ID 產生 OBS 用的網址，並逐一複製已寫入名稱與顏色的 CSS
- 可在預覽中調整數值確認、自動計算瀏覽器來源尺寸、復原／重做、自動儲存、專案檔

## 運作方式

在 OBS 的瀏覽器來源開啟 `https://ccfolia.com/rooms/{房間ID}/characters/{角色ID}`，CCFOLIA 會顯示只有該角色頭像與狀態的畫面。本工具產生的，就是覆寫這個畫面外觀的 CSS。

畫面結構是從 CCFOLIA 發布的 JavaScript 解讀而來（2026-09-14）。

```
#root > div > div
  span.MuiBadge-root   … 頭像 + span.MuiBadge-badge（先攻值）
  div > div[variant="bar"]
    div                … 一條狀態（最多 8 條）
      div > p（標籤）+ p（<span color>目前值</span>/最大值）
      div > div（底色）+ div（伸縮的部分, style="width: 83.3333%;"）
```

- 數字的 `span` 在**目前值降到最大值的 80% 以下**時會變成 `color="secondary"`（不是 0 以下）
- 剩餘比例是用 `style` 屬性的開頭比對（例如 `[style^="width: 8"]`）判斷，再用 `:has()` 對整條的容器套用效果。`:has()` 需要 OBS 30（Chromium 105 以上）
- 這個畫面沒有名稱，所以用 `:root { --name: "…" }` 寫進 CSS，再以偽元素顯示
- 預覽（`mock.v1.js`）連 CCFOLIA 原本的樣式也一併重現，因此 CSS 若漏了覆寫，預覽也會同樣跑掉
- 實際頁面中 `#root` 會撐滿畫面高度，且寬度不含留白（content-box）。這是在 OBS 上實測得知的，預覽也做成一樣。CSS 這邊會讓整體高度依內容調整，並對決定尺寸的元素加上 `box-sizing: border-box`

## 擴充方式

- **設計範本** — 在 `presets.v1.js` 的 `DESIGNS` 加一筆，只需寫出相對於 `BASE_LOOK` 的差異
- **裝飾** — 在 `presets.v1.js` 的 `DECO_TYPES` 加上名稱與調整項目（`controls`），並在 `deco.v1.js` 的 `DECOS` 加上產生 CSS 的函式。UI 會依 `controls` 自動產生
- **狀態條形狀** — 在 `presets.v1.js` 的 `SHAPES` 加上名稱，並在 `shapes.v1.js` 的 `PATHS` 加上產生路徑的函式。外框是把路徑加粗後自我裁切，因此任何形狀都能貼合內側
- **字型** — 加進 `presets.v1.js` 的 `FONTS`。`weights` 只能填 Google Fonts 實際存在的字重（要求不存在的字重可能會導致整個載入失敗）

## 注意事項

- CCFOLIA 的畫面結構若有變動，顯示可能會跑掉
- 使用 Google Fonts，因此執行 OBS 的電腦必須能連上網路
- 設定為「隱藏狀態」的角色，除了擁有者以外都看不到狀態條（CCFOLIA 的規格）
- 中文字型已全面改用 Google Fonts 上帶有 `chinese-traditional` 子集的家族（思源黑體／宋體、昭源黑體／圓體、霞鶩文楷、粉圓體、芫荽、仙人掌明體等），字形為繁中寫法
- Google Fonts 沒有繁中點陣字型，因此「復古遊戲」範本改用等寬的霞鶩文楷等寬（`LXGW WenKai Mono TC`）保留固定寬度的排版感
- 標示「含注音」的字型（`Bpmf` 系列）會在字旁附上注音符號，適合兒童向或教學場景

## 本地預覽

```bash
python -m http.server 8123
```

也可以直接以瀏覽器開啟 `index.html`；但「從清單選擇」本機字型的功能需要 `http://localhost` 或 `https://` 才能使用。
