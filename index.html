TRPG OBS工具

把 CCFOLIA 角色的 HP、MP、SAN 等數值，用你喜歡的樣式顯示在 OBS 上，產生對應的「自訂 CSS」。數值會和 CCFOLIA 連動。所有處理都在瀏覽器內完成，輸入的內容不會傳送到任何地方。

OBS 的設定

  1. 新增來源 →「瀏覽器」。在網址欄填入角色的網址：
    https://ccfolia.com/rooms/{房間ID}/characters/{角色ID}
  2. 在寬度與高度填入上方顯示的 瀏覽器來源尺寸。
  3. 把「自訂 CSS」欄位的內容全部刪除，貼上剛才複製的 CSS。
  4. 如果畫面仍是一片空白，在來源上按右鍵 →「互動」，登入 CCFOLIA 並進入房間（做過一次就會記住）。
  5. 第二位角色開始，請用「新增來源」→「瀏覽器」重新建立，網址與 CSS 都換成該角色的。瀏覽器來源受 OBS 限制無法複製（「貼上（複製）」會呈灰色），若用「貼上（參照）」增加，所有人都會變成同一個角色。尺寸與位置可用右鍵 →「複製變形」→「貼上變形」統一。

CCFOLIA 的設定

  • 角色「狀態」的排列順序會對應到第 1 條、第 2 條…的顏色（例：HP → MP → SAN）。
  • 在聊天室輸入 :HP-3、:SAN=45 之類的指令，OBS 這邊也會立刻更新。
  • 設定為「隱藏狀態」的角色，除了擁有者以外都看不到狀態條。

要使用電腦已安裝的字型時

  • 在字型欄選擇「自行輸入名稱（本機字型）」並填入字型名稱。在 Chrome / Edge 可用「從清單選擇」直接看外觀挑選電腦內的字型（第一次會詢問是否允許使用字型）。
  • OBS 是用自己電腦上的字型顯示，所以執行 OBS 的電腦也要安裝同一套字型。若沒有安裝，會變成一般的黑體。
  • 不含中文字的字型，中文的部分會變成一般的黑體（可用清單範例中的「永」字確認）。
只靠瀏覽器就能執行的免費工具。產生的 CSS 可自由使用。
CCFOLIA 的畫面結構若有變動，顯示可能會跑掉。本工具與任何服務皆無關聯，屬於非官方工具。
